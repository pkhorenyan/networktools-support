# Network Tools — Support

A network engineer's toolkit that runs entirely on your iPhone: ping, traceroute, DNS, port and LAN
scans, TLS, HTTP, WHOIS, Wi-Fi quality, speed tests, Wake on LAN, an IP calculator, an offline MAC
vendor database, and a full SSH client with jump hosts, port forwarding, `scp` and key management.

There is no account, no server of ours, and nothing about you is collected. See
[PRIVACY.md](PRIVACY.md).

## Getting help

**Report a problem or ask for a feature:**
[open an issue](https://github.com/pkhorenyan/networktools-support/issues).

**No GitHub account?** Email **pavelkhorenyan@gmail.com** instead. Please put "Network Tools" in the
subject.

## What to put in a report

This app is meant to be arguable: where it infers something rather than measuring it, it shows the
observations behind the answer. So the most useful reports say what you expected as well as what
happened.

1. **Which screen** — Ping, LAN scan, SSH, and so on.
2. **What you expected, and what appeared.** If a verdict looks wrong, say why you think so.
3. **Your iOS version and iPhone model** — Settings → General → About.
4. **The app version** — it is on the App Store page under Version History.
5. If a measurement is involved, the **Share** button in the top right of most screens copies the
   whole run as text. Paste it in. It contains only what is on the screen.

Please do not paste private keys, passwords, or anything from a server you would not want public.
A fingerprint or an error message is enough.
