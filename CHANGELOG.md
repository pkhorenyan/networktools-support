# Changelog

## 1.0.0

First release. Seventeen network tools that run entirely on the phone.

**Diagnostics** — ping, traceroute, DNS (every record type at once, any resolver, DNS-over-HTTPS,
and a comparison mode that flags the resolver that disagrees), port scan with banners and service
names, LAN discovery that names and classifies what it finds, HTTP check with the DNS/connect/TLS/
TTFB split and a security-header audit, TLS inspection down to the full certificate chain, WHOIS
followed to the registrar that actually holds the record, Wi-Fi link quality and a walking survey,
speed test, iperf3, an IP calculator with VLSM subnet division, an offline MAC vendor database,
Wake on LAN, and a network interface list with live throughput.

**SSH** — a client written from the protocol up, with jump hosts, local port forwarding, `scp`,
`ssh-copy-id`, key generation, import and export, command snippets, and a real VT/xterm terminal
with the keys a phone does not have.

**Six themes**, four dark and two light, including a true-black high-contrast one for sunlight.

No account, no backend, nothing collected.
